# Error Model

Stable machine-readable error codes are part of the API contract.

## Payment

```text
PAYMENT_NOT_FOUND
PAYMENT_EXPIRED
PAYMENT_ALREADY_SUBMITTED
PAYMENT_SIGNATURE_MISMATCH
PAYMENT_AMOUNT_MISMATCH
PAYMENT_ASSET_MISMATCH
PAYMENT_TREASURY_MISMATCH
PAYMENT_REQUIRES_REVIEW
```

## Banking

BANK_REFERENCE_INVALID
BANK_REFERENCE_ALREADY_USED
BANK_SETTLEMENT_NOT_OBSERVED

## Treasury

## Reconciliation

```text
RECONCILIATION_REFERENCE_UNKNOWN

RECONCILIATION_ASSET_MISMATCH

```

## Example

```json
{
  "error": {
    "code": "RECONCILIATION_AMOUNT_MISMATCH",
    "message": "Observed settlement amount does not match the payment intent.",
    "requestId": "req_xxx",
    "correlationId": "cor_xxx"
  }
}
```

Error messages sent to clients must not leak secrets/provider credentials or sensitive internal details.
